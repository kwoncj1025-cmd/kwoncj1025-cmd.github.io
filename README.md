# Chanjun Kwon — portfolio site

Live at **https://kwoncj1025-cmd.github.io/**

This is the built, single-file deployment of my portfolio: an ID badge on a lanyard, a deck of glass cards, and a MacBook that opens the live sites, all inside one 3D stage. Hand-built with GSAP and Three.js. It is public only because GitHub Pages needs it to be.
